This is an update to inferMM 0.1.1, published on 2026-10-30.

This update is being submitted earlier than the usual release interval to correct the
omitted lowest-concentration observations in the bundled SDL dataset. sdl_demo now
contains 192 reaction-level rates: six enzyme variants, eight concentrations, and
four reactions per concentration. Data provenance and preparation are documented.

The update also adds default screening of four fixed working variance shapes in
fit_mm(). Explicitly specified shapes retain their previous calculations; setting
variance="log" preserves the former default. The separate log/power-grid "auto"
option is retained. Package citation versions and DOI markup have been corrected.

examples, 694 tests, vignette rebuilding and PDF manual check passed.

so optional HTML validation and math-rendering checks were skipped.
